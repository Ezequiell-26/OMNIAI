# Third-party notices

OMNIAI is licensed under the MIT License for its own source code.

## Current status

The repository currently contains a curated reference registry for MIT-licensed agent projects in `docs/open-source/mit-agent-references.md`.

At this stage, no upstream project source code is declared as vendored or copied into OMNIAI by that registry. References are used to guide independent implementation and architecture decisions.

## When code is imported

Before importing source code from an external project, record:

- project name and repository URL;
- exact license and relevant version/commit;
- upstream copyright holder(s);
- imported file/path(s);
- required license/copyright text;
- any additional attribution or notice requirements.

MIT-licensed code can generally be reused with preservation of the copyright and permission notice, but the exact upstream license and repository scope must still be checked before every import.
